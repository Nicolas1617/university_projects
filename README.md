## Projects

### 1. ESIB — Biomedical Signal and Image Processing

[View project](https://github.com/Nicolas1617/university_projects/tree/main/ESIB%20project%20work)

**Course:** Elaborazione di Segnali e Immagini Biomediche

This project explores biomedical image processing and quantitative analysis, with a particular focus on radiomics and feature extraction from medical images.

**Technologies:** Python, Scikit-learn, Matplotlib, PyRadiomics, MATLAB.

**Main activities:**
- Medical image and ROI import
- Image and ROI visualization
- ROI histogram analysis
- Radiomic feature extraction
- Feature storage and manual comparison
